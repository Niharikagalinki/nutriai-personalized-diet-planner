# NutriAI – Personalized Diet Planner
🌐 Live Demo
[Open NutriAI – Personalized Diet Planner](https://niharikagalinki.github.io/nutriai-personalized-diet-planner/)

NutriAI is a web-based personalized diet planning application developed using HTML, CSS, and JavaScript. It generates a customized diet plan based on the user's basic health information, fitness goal, activity level, dietary preference, food preferences, and allergies.

## Features

- BMI calculation and BMI category
- Personalized calorie estimation
- Goal-based calorie adjustment
- Weight loss, weight gain, and maintenance plans
- Vegetarian and non-vegetarian meal selection
- Allergy-aware meal filtering
- Protein, carbohydrate, and fat recommendations
- Personalized explanation of the generated plan
- Breakfast, lunch, snack, and dinner recommendations
- Generate Another Plan functionality
- Input validation
- Responsive and professional user interface

## How It Works

1. The user enters their basic details such as name, age, height, and weight.
2. The user selects a fitness goal.
3. The user selects their activity level and dietary preference.
4. Food preferences and allergies can be provided.
5. NutriAI calculates BMI and estimates daily calorie requirements.
6. The application adjusts the calorie target according to the selected goal.
7. Suitable meals are selected based on dietary preferences, allergies, and the user's goal.
8. The personalized nutrition summary and meal plan are displayed.
